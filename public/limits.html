Limits

Pastty is built for quick hops between devices. These caps keep it fast and fair for everyone.

Open Pastty Free · No app · No account

Per room and per item

WhatLimit
Text10 KB per message
Images5 MB each · PNG, JPG, WEBP
Videos50 MB each · MP4, WEBM, MOV
Devices5 per room
Room time5 minutes; every join or reconnection renews it
ReconnectingA device that drops has 60 seconds to rejoin
Sending rateAbout 30 messages and 128 MB per minute from one network address

What happens at a limit

If something is too big or in a format Pastty does not take, it is refused and you see a short message saying why. If you send very fast, Pastty asks you to slow down for a moment. Nothing is cut off silently.

What Pastty is not for

Pastty is a live link between your devices, not storage. It does not keep items for later, it does not send other file types such as PDFs or ZIPs, and it is not meant for very large files.
